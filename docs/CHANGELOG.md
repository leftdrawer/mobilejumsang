## v1.1.1 — 2026-09-25

- **산통 뽑기 연출 변경 (은호당님 지시).** 옆으로 기울이던 방식을 버리고, 뽑힌 산가지가 원래 자리에서 곧게 위로만 솟아(`RISE_H=0.055`) 나머지와 나란히 서되 확실히 도드라지는 방식으로. 번호판도 수직으로 세워 카메라 향함.
- **산통 카메라 조정.** 통이 화면 위로 올라가 보이던 문제 → `CAMS.santong`을 `pos:[0,0.055,0.235], look:[0,0.045,0]`로. 통 전체와 솟은 산가지가 프레임에 들게.

## v1.1.0 — 2026-09-25

- **산통(算筒) 점 추가.** `gSantong` 블록, 64수 데이터(`ST_TEXT`, 길흉 7등급), 통+산가지 메시, 흔들기 애니메이션, 번호판(한자 數), 첫 화면 진입점, pointerdown 분기, buildUI 화면 분기.
- **산통 뽑기 연출 재작성.** 산가지를 통에서 완전히 빼내 위로 솟구치던 방식(화면 밖으로 사라짐)을 버리고, 통 입구(`PIVOT_Y = TUBE_H*0.86`)를 회전 축으로 삼아 산가지를 옆으로 눕히는 방식으로 바꿨다. 밑끝은 통 안에 걸쳐 남고 위쪽만 비스듬히 밖으로 나온다. 회전 공식: 중심 = 피벗 + Rz(ang)·(0, dCenter). done 상태에서 최종 기울기를 명시적으로 고정해 결과 화면에서도 삐져나온 채 보이게 함.
- **개발 문서 추가** (`docs/PROJECT.md`, `docs/CHANGELOG.md`, `docs/APP_ARCHITECTURE.md`). 앱 코드 개발자를 위한 진입점·이력·구조 문서.
- 미확정: 첨시 문구와 산통 법식(64수 배치·길흉 등급)은 Kiro 초안이며 **은호당님 감수 대상**. 연출도 은호당님 확인 전.
