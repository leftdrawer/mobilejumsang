  - **상 폭 IN_W: 0.371984m → 0.323984m**(−4.80cm, −12.9%). 식 `2*(G_OUT+0.042)` → `2*(G_OUT+0.018)`. `TW`도 0.403984 → 0.355984m로 자동 축소. `IN_D=0.300`·`LEG_H=0.26` 보존.
  - **5무구 좌표(x, y, m):** 오방기 (−0.143992, 0.0, 세로) / 쌀 (−0.055, +0.055) / 엽전 (−0.055, −0.088992) / 산통 (+0.055, +0.033992) / 육효 (+0.055, −0.088992). 가로 열 대칭(`−G_IN·φ²`/`−G_IN`/`+G_IN`), `KNIFE_X` 제거. 세로는 18판 승인 φ 배치 보존.
  - **index.html:** 대신칼 3D 블록 전체(`gSinkal`·`CAMS.sinkal`·`SK_*`·`startSinkal`/`throwSinkal`·Verlet 술·`window.__sinkal` 디버그 훅·장판 바닥) 제거, 입력/화면/buildUI 대신칼 분기 제거, `HOME_HOT`에서 sinkal 키 제거.
  - **blender:** `home_scene.py`에서 대신칼 블록·`KNIFE_X`·`tassel_fill` 보조광 제거, IN_W 식 교체, 초점 상향. 첫 화면 재렌더 `home_v22`(v21 보존), `--hex 117`(水地比) 고정, f/8, 카메라 당김(설계 시작값 `--camd 0.455`).

## v1.1.0 — 2026-09-25

- **산통(算筒) 점 추가.** `gSantong` 블록, 64수 데이터(`ST_TEXT`, 길흉 7등급), 통+산가지 메시, 흔들기 애니메이션, 번호판(한자 數), 첫 화면 진입점, pointerdown 분기, buildUI 화면 분기.
- **산통 뽑기 연출 재작성.** 산가지를 통에서 완전히 빼내 위로 솟구치던 방식(화면 밖으로 사라짐)을 버리고, 통 입구(`PIVOT_Y = TUBE_H*0.86`)를 회전 축으로 삼아 산가지를 옆으로 눕히는 방식으로 바꿨다. 밑끝은 통 안에 걸쳐 남고 위쪽만 비스듬히 밖으로 나온다. 회전 공식: 중심 = 피벗 + Rz(ang)·(0, dCenter). done 상태에서 최종 기울기를 명시적으로 고정해 결과 화면에서도 삐져나온 채 보이게 함.
- **개발 문서 추가** (`docs/PROJECT.md`, `docs/CHANGELOG.md`, `docs/APP_ARCHITECTURE.md`). 앱 코드 개발자를 위한 진입점·이력·구조 문서.
- 미확정: 첨시 문구와 산통 법식(64수 배치·길흉 등급)은 Kiro 초안이며 **은호당님 감수 대상**. 연출도 은호당님 확인 전.
